## Run on yanglab after SSH recovery

Use a new worktree of this branch, preserving all existing worktrees. Reuse the
existing runtime without installing or upgrading dependencies:

```bash
cd /home/tongji/alex/rm65-wide-layout-20261015
D=experiments/rm65_handoff_v1
source "$D/runtime.sh"
"$RM65_PYTHON" "$D/render_layout.py" \
  --layout "$D/scene_v2_wide180.json" \
  --output "$D/evidence/layout_wide180_render_01"
```

The output directory must not exist. This entry point creates one shared scene,
settles 100 steps (0.4 s) under the original safety checks, and captures four
raw RGBs, their calibration, a four-view montage and a separate scene preview.
It verifies **actual** articulation base positions and the actual calibrated
overhead axis, saving `layout_verification.json`. It executes no action groups
and imports no bridge or hardware client. A failed verification raises an error.

To explicitly select this layout in a future physical-baseline process:

```bash
export RM65_LAYOUT="$PWD/$D/scene_v2_wide180.json"
```

That selection alone does not qualify the old handoff candidate or authorize
model generation. Layout preview is the scope of this change.
