DA3-Small 官方卡列出 Relative Depth / Pose Estimation / Pose Conditioning，名义0.08B、Apache-2.0。
卡上自动 safetensors 参数统计与正文名义参数数不一致；不将任一数字换算成已测显存。
API 源码接受 image list、extrinsics(N,4,4 world-to-camera)、intrinsics(N,3,3)。
align_to_input_ext_scale=True 时源码通过相机 pose alignment 得到尺度，替换输出相机外参并调整 depth；
这利用公开标定米制相机基线，不是读取物体GT。零/极小基线无法给出可靠尺度，首版拒绝<1cm基线。
输出 depth/conf、外参和与处理后图像对应的内参；必须使用输出内参反投影并映射原图像素，不能只按长宽盲缩放。
Small 不需要/不提供本项目所需的3DGS；GS分支文档限制在 Giant/Nested 模型，本实现 infer_gs=False。
官方依赖包含 torch/torchvision、xformers、numpy<2、omegaconf、evo、e3nn 等；
API 导入 export 相关模块，不能假定“只用 depth”就完全不需要官方安装依赖。gsplat 是独立可选项。
DA2 Metric 官方 Small 为24.8M、提供室内Hypersim权重和直接米制输出；它是单图对照而非DA3等价替换。

运行挂载与待验收合同

宿主显式 --world-head-config 指定专用 venv、DA3-SMALL 权重目录、两个文件 SHA256、上游源码 commit、分辨率、deadline。
配置不可从研究 policy RPC 注入。配置在场景创建前检查；缺依赖/设备/权重失败，不启动替代几何或 CPU fallback。
配置模板 da3_runtime.example.json 故意不能直接作为有效配置；禁止把占位符算作已固定源码/权重。
目前 source_revision 是宿主配置声明，实际安装内容与该上游 commit 一致性必须在依赖准备验收中核对并归档；
不能仅靠40字符形式检查声称安装来源已验证。应使用固定commit构建 wheel，记录 wheel/lock、package文件hash。

bwrap: /usr与现有基础venv只读；学习venv重映射 /lwh-venv；权重 /weights只读；公共冻结输入 /input只读；
worker代码 /code只读；/tmp tmpfs；仅绑定 nvidia0/nvidiactl/nvidia-uvm；无网络、无 workspace/private/score/SDK 挂载。
HF_HUB_OFFLINE=1；local_files_only=True；模型日志到stderr，JSON结果独占stdout。
不要用 editable 安装引用被隔离的源码绝对路径；新venv必须可重定位、Python基于可挂载的/usr运行时。
CUDA driver库、Blackwell架构支持和 bwrap GPU设备实际可用性仍需真实 worker 冒烟验收，宿主 nvidia-smi 不能替代。
每个作业首版冷启动加载权重；记录 load_s / inference_s / worker_compute_s / peak_allocated / peak_reserved。
ProcessJob记录请求、启动、返回、隔离命令与超时；完整墙钟必须包含模型加载/图片拷贝/CPU融合/等待。
这版不声称已达到“廉价”；若冷启动开销主导，再在相同 Worker 边界内研究常驻模型，不能先删成本。

建议独立资源验收（尚未授权执行）

先完成专用依赖/权重/源码hash审查，再对已存合法RGB做最多3个冻结输入的本地forward，Astra=0，SAPIEN=0。
从3视角336输入开始，一次在途；不同时改分辨率和模型。OOM/NaN/不保留标定尺度立即失败，无自动降分辨率重试。
拟定资源gate：在目标机器上 learned worker峰值reserved<=5GiB，为SAPIEN/渲染留空间；总GPU占用另记。
本地粗检查目标墙钟<=2s是待检验工程目标，不是已测性能；超过目标先报告，不把额外等待藏在异步里。
初次3样本只作冒烟，不能计算可靠p95或泛化；有独立布局后再报告质量/coverage与时延分布。
质量gate由独立评分方在不进入在线路径的GT/人工标注上评分：几何误差、coverage、unknown、跨视角一致性、小目标漏检。
表面支撑本来不是object center，不以偷换GT中心坐标评价“修正后成功”；准备位姿质量需单独定义。
