可信 host 接口（不暴露为模型可调用工具）

1. 将公开观测与封存 Geometry World 按现有 PublicStore 注册。
2. import_grounding_archive(store, archive, manifest_sha256, world_id, evidence_id)
   验证原始 raw/Schema/请求/三路 RGB/epoch/revision/read set 并注册来源 receipt。
3. WorldHead.bind_semantic_grounding(world_id, evidence_id, task)
   调用现有 publish_world；新的 revision，几何不变。
4. store.query_world(new_world_id) 获取模型紧凑视图。
5. shadow_request(world, observation, task, task_binding)
   task_binding.object_id 必须是 semantic task selection；H4/m1/K0；永不执行。
6. Broker.prepare(request) 只生成正式 wire/schema，零 worker / 零调用。

恢复已有 revision 而不重新发布：
 import_grounding_archive(...) 后调用
 restore_persistent_world(store, frozen_world, trusted_world_id_pin, trusted_task_pin)
 再 validate_persistent_world(store, frozen_world)。不能盲目把未验证 JSON 或自称 MODEL_RAW 注册为可信 world。
