实现与可信边界
继续使用 PublicStore、WorldHead 与原来源合同。估计器算法/几何参数不变。
新增 verification_cache，仅管理来源证明和已经哈希验证的不可变 bytes 快照。
World/Observation/Evidence/receipt/pin 的正常嵌套 JSON 修改及整个 registry 替换会使依赖 token 失效。
缓存还比较调用方给出的完整 World 字节；不只凭 world_id 命中。
当前新增 RGB-D 每次 API 都从文件读取并完整验 hash/协议/数组/FK/时间/反馈。
同一 API 内复用只读、由 bytes 支撑的深度数组；不跨 API 复用当前观测验收。
祖先证明共享链式结构，不在每次 revision 复制整条祖先依赖；祖先原始传感器字节留在不可变快照中。
历史源文件没有被宣称为不可变。路径 inode/size/mtime/ctime 变化会触发原始哈希复核；路径逃逸继续拒绝。
即使修改同尺寸数据后恢复 mtime，也会因 ctime/内容变化拒绝。文件读取前后变化会拒绝。
不可变的是保存的 bytes 和证明记录，不是原磁盘路径，也不是可变 registry 本身。
完整递归审计保留为 validate_geometry_update(store, world, full_audit=True)，跳过缓存，重新读取/校验原始文件及所有祖先。
当前 epoch/read_versions/FK/反馈绑定及原篡改拒绝均保留；新增发布前当前观测变化检查。
Owner、Supervisor、IK、碰撞、STOP、ActionChunk与所有模型合同/启动路由未变。
这是单 Owner 同步可信主机优化，不是抵抗任意进程内 monkeypatch 或恶意内核/文件系统的安全边界。
直接绕过 Python 覆写器的底层 mutation 或篡改缓存私有 token 不在可信宿主模型内；不向模型暴露这些接口。

限制
旧磁盘文件仍可变；元数据检测依赖正常本地文件系统语义，不用于对抗可伪造ctime的恶意内核。
历史guard和token遍历仍线性，缓存内存随保存的世界/传感器证据增长；没有宣称长时无限容量或实时性能。
没有新的receipt跨进程恢复API；恢复后需重新完整验收，不能盲信持久化cache hit。
本轮只给出单场景开发回放与软件机制证据，没有新增独立物理成功率或语义性能结论。
