# 02 — 双臂交接香蕉

**阶段目标**：左臂主动调整香蕉的空间位置与朝向，配合右臂形成容易接取的相对位姿 → 右臂接稳 → 左臂松开撤离。香蕉是**弯曲的**。

- **先居中，再下降，最后闭爪——左右臂及掉落后重抓均适用**：在下降接近和闭合前，必须先结合本臂腕部 RGB 与固定视角确认：香蕉预定夹持截面位于本臂两片指垫内侧之间的中间，而不是单侧指垫外缘、指尖下方或夹爪本体旁。先在有间隙的位置完成横向对中及朝向调整，下降过程中持续保持这一关系；偏心时停止下降，重新对准，不能靠下压、顶推或原地闭合解决横向错位。单片指垫与香蕉轮廓重叠不等于居中，这一前提优先于下面的视觉深度经验。遮挡或视角冲突时不能宣称已居中，应自主选择能澄清关系且有净空的调整。香蕉掉落、被推移或转动后，旧对准关系失效，必须按当前位置重新对准，不照搬旧抓取位置或继续累计下降。
- **左右臂直接采用20%抓取开度**：完成对中并达到有效夹持深度后，左臂初次抓取、重抓及右臂接取均直接命令 `gripper_opening=0.20`（剩余20%开度，raw目标200），不再先25%再收紧。20%是目标开度，不是夹持力，也不是抓取成功证明；张爪接近和释放仍使用张开命令。危险或错位时先修正空间关系，不盲目闭爪或自动继续收紧。

- **先高低错层接近，再对准下降接取（优先于同时靠近的通用建议）**：左臂完成抓取验证后，先建立“左侧持物较低、右侧接取夹爪较高”的物理空间关系，不让两爪在同一接触高度直接相向横移。左臂在整根香蕉持续离桌、夹持稳定且有扫掠净空的前提下，从较低位置呈递香蕉；右臂保持张开，先升到待接取香蕉局部的上方，调整腕部朝向，使右腕 RGB 能看到香蕉待夹取部位及两片右指垫。若左臂已经处于合适的较低位置，无需为了错层再次下降；不能以香蕉擦桌换取高度差。
- **先平移/旋转对准，后下降，最后闭爪**：在右指垫与香蕉仍有可见间隙时，完成横向对中、接近位置和局部夹取朝向调整，保持右爪从上方接近的空间关系；再由 Astra 选择有界的下降动作，使香蕉进入两片右指垫内侧，取得足够实际夹取深度后，另一步闭爪。不要在尚未对准时一边横扫香蕉、一边下降，也不要由左臂继续把香蕉顶向右爪外侧来“补足深度”。如果发生顶靠或香蕉被推转，先自主解除干涉、恢复间隙，再对准；下降本身不能代替对准。
- **高度和动作由当前观测决定**：这里的“左低右高”指实际夹指与香蕉待夹取局部相对桌面的关系，不是直接比较两臂各自控制器的 TCP-Z；两臂工作坐标系不同，夹指位置还随姿态与开度变化。不规定固定高度差、升降距离或专家 waypoint。平移与旋转的数值、哪只手先调整及何时下降仍由 Astra 决定，原有 IK 与物理保护保持生效。错层有助于观察但不保证无碰撞；右腕遮挡时结合固定视角调整观察姿态，不盲目下降。

- **双臂主动协同，不要默认左臂固定。** 左臂已夹稳香蕉后，交接姿态应由**左右臂共同调整**：左臂可优先沿 X 靠近并旋转腕部改变香蕉朝向和自由端位置；右臂可同时优先沿 X 靠近并旋转腕部，使两片接取指垫对齐香蕉局部夹取部位。
- **汇合的主要位移方向是 X，而不是 Y。** 左臂带着香蕉、右臂张开夹爪相向靠近时，优先让**左右两臂分别沿自身工作坐标系的 X 轴**缩小前后/接近距离；每臂具体采用 +X 还是 −X 由当前姿态、画面及动作反馈决定，不把两臂的坐标系误当作同一个。**Y 主要用于横向对中**：在腕部 RGB 看到香蕉不在两片指垫之间的中央时，再用对应机械臂的 Y 位移纠正偏心。不要继续把左右臂大幅反向 Y 平移当成默认“汇合”。Y 对中、X 接近和必要的腕部旋转可按场景灵活组合，无固定轮数或额外方向核验门槛。
- **主动让香蕉去适应右爪，不只是让右爪去追香蕉。** 若右臂离香蕉仍较远、角度不合适、伸入不足，或某个右臂接近动作被 IK 拒绝，就考虑**移动/旋转左臂呈递香蕉**，缩小双方相对距离并改善进入角度；不要把左臂长期保持原姿态作为默认交接策略。
- 空隙明显且两臂动作相容时，可在同一个 `parallel` 动作组里给左右臂各一个动作，让**左臂带着香蕉向右臂靠、右臂张爪向香蕉靠，必要时两臂同时旋转/平移**；也可以根据画面选择先改变左臂呈递姿态、再让右臂精调。**不是要求每一轮必须双臂一起移动，也没有固定等待轮数。**
- **旋转注意避碰**：左臂旋转会扫动香蕉自由端，右臂旋转会扫动指垫；结合现有可见空隙，避免香蕉、夹爪与另一臂、桌面、盘沿发生明显碰撞。此提醒不增加额外观测门槛或固定等待。
- **右爪的夹取条件与左爪的桌面视角条件不同，不能混用。** 右臂用**右腕 RGB** 判断：香蕉的待接取局部应位于**两片右指垫的内侧之间**，而不只是某片指垫在图像中与香蕉边缘重叠一点点。两片指垫接触面尽量与该处香蕉的**局部切向/待夹取边缘平行**；必要时让右腕**先旋转调整夹取朝向**，再用平移把开口对到香蕉上，并沿适合夹取的方向增加实际进入深度。**右臂与左臂的视觉深度经验不同：右腕 RGB 中通常需要看到香蕉待接取部位进入两片指垫约 20–30 mm 的明显深度，而不是仅在垫尖擦过一点；左臂桌面相机的不足 10 mm 轻微越过规则不能移植给右腕。** 这里的 20–30 mm 是现场经验提示，不是直接下降的位移指令；若错位，优先用平移、旋转及左臂呈递去改善对准和插入，不要为了满足深度数字盲目下压。
- **避免“轻微遮盖 → 继续下降 → 顶走香蕉”的已发生失败。** 若右腕图只显示指垫擦到香蕉边缘、自由端位于指尖外侧或仅浅浅重叠，**不要把这个重叠误认为已经夹入两垫之间，更不要只靠继续向下压或直接闭爪解决**。改为让**右臂实际平移、调整俯仰/朝向或改变接近方向**；左臂也可主动平移/旋转持有的香蕉，使待夹位置主动进入右爪开口。两臂选择有进展的相对位姿修正后，再闭爪。
- 若本次接近已把香蕉顶偏/推开，按变化后的**实际画面**重新对准（必要时退开一点、重新张开右爪），不要在偏移位置反复下降或闭爪。**不要因为无法完美量化偏差就进入连续空动作；用当前 RGB 和反馈做合理的主动修正。**
- 如果浅入或闭空，优先让**两臂重新协调相对位置与姿态**，不要反复原地收紧右爪。左臂保持实际持物，直到右臂真正接稳；右臂接稳后左爪松开并撤回。在空隙合适时，左臂撤回与右臂持香蕉直线后撤也可以并行。

**离开本阶段的目标状态**：香蕉由右臂持有，左臂已经松开并撤离，右臂开始向蓝盘放置。
